La mise à jour pour gérer le délai d'inscription sur la page d'enregistrement (`pages/RegistrationPage.tsx`) est maintenant terminée.

J'ai effectué les modifications suivantes :

*   **Ajout des dates de début et de fin d'inscription** à la table `site_settings` via le fichier `databases/09_site_settings.sql`. Vous devrez exécuter ce script SQL sur votre base de données (si ce n'est pas déjà fait) pour que ces paramètres soient disponibles.
*   **Mise à jour de `pages/RegistrationPage.tsx`** pour :
    *   Récupérer dynamiquement les dates `registration_start_date` et `registration_end_date` à partir des paramètres du site.
    *   Afficher un message d'alerte (`info`, `warning`, ou `danger`) en fonction de la période d'inscription (pas encore ouverte, fermée, ou se terminant bientôt).
    *   Désactiver le formulaire d'inscription si les inscriptions ne sont pas ouvertes ou sont closes.
    *   Utiliser `axios` pour les appels API pour plus de cohérence.

**Pour voir ces modifications, veuillez IMPÉRATIVEMENT :**

1.  **Exécuter le script SQL mis à jour** pour `databases/09_site_settings.sql` sur votre base de données.
2.  **Redémarrer votre serveur backend** (`cd server` puis `npm start`).
3.  **Redémarrer votre application frontend** (`npm start` dans le répertoire racine du projet).

Après ces étapes, vous devriez voir les messages d'alerte et la logique de désactivation du formulaire fonctionner sur la page d'inscription en fonction des dates que vous avez configurées dans `site_settings`.
