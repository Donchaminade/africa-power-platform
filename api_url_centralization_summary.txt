J'ai centralisé l'URL de l'API (`API_URL`) comme demandé.

Désormais, au lieu d'avoir `const API_URL = 'http://localhost:4000/api';` répété dans de nombreux fichiers frontend, tous les composants importent cette constante depuis un fichier de configuration unique : `utils/config.ts`.

Cela améliore la maintenabilité du code : si l'URL de l'API change à l'avenir, il suffira de la modifier à un seul endroit (`utils/config.ts`).

**Les fichiers suivants ont été mis à jour :**

*   `components/Testimonials.tsx`
*   `admin/components/ui/ImageUpload.tsx`
*   `admin/components/management/UsersManager.tsx`
*   `admin/components/management/TestimonialsManager.tsx`
*   `admin/components/management/TeamManager.tsx`
*   `admin/components/management/SponsorsManager.tsx`
*   `admin/components/management/SpeakersManager.tsx`
*   `admin/components/management/SeoManager.tsx`
*   `admin/components/management/ProgramManager.tsx`
*   `admin/components/management/GalleryManager.tsx`
*   `admin/components/management/management/FaqManager.tsx`
*   `admin/components/Login.tsx`
*   `admin/components/Dashboard.tsx`

**Pour que cette modification prenne effet, veuillez IMPÉRATIVEMENT redémarrer votre application frontend :**

```bash
npm start
```

Veuillez vérifier que l'application fonctionne toujours correctement après ce changement.
